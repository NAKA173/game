# 2. 新規に決まったこと（要実装・サマリー）

## 2.1 ストーリー・キャラクター（`story_bible_v1.md` 参照）
- **主人公は3人**：常盤朔（新市街）・宮野灯里（旧市街）・冬野玲（中盤で仲間になる元ライバル）
- **操作キャラは3人から1人選択**。8章の合流イベント以降、玲も選択可能になる
- **あわいものパーティは合計6体**：前衛3体＋控え3体。前衛3体だけが実戦に出る
- 中ボス3体（鐘尾硯・一色誉・カクテイの分身）、それぞれ固有の相棒あわいもの
  （未決裁＝デバフ技、更地喰らい＝戦闘中にフィールドが崩れていくギミック）を持つ
- 支線終点4駅（清水・段畑・渡瀬・彼岸）に隠しボス「ヌシ」を配置

### コードへの影響（優先度：高）
- [ ] **キャラクター切り替えシステム**：`main.js`のPオブジェクトを、朔/灯里/玲の3人ぶん持てるように拡張する必要がある
      （現状は単一の`P`オブジェクトのみ。3人分のステータス・スプライトパレットを持つ構造に変更）
- [ ] **前衛3体/控え3体のパーティ管理**：現状`battle.js`の`ally`は単数のみ。配列化し、
      前衛3体が同時に戦えるようにする必要がある（既存の`foeAI`のターゲティングロジックも複数味方対応が必要）
- [ ] ボス固有ギミック（デバフ・地形破壊）はまだ仕様のみ。実装は後回しでよいが、
      `battle.js`の敵定義に「特殊行動パターン」を追加できるよう、`makeFoe()`を拡張しやすい形にしておくと後が楽

# 3. Claude Codeへの申し送りとしての推奨アクション

今すぐ着手してほしい順（このチャットからの推奨）：

1. **今進めている「離散的マップ＋駅間移動」を完了させる**（すでに依頼済みの作業、そのまま継続）
2. **キャラクター切り替え＋前衛3体パーティ管理**の土台を作る（§2.1のコード影響を参照）。
   ストーリー実装より先にこの土台がないと、玲の合流シーンなども実装しようがない
3. **セーブ機能（日記アプリ）**を作る。プロトタイプの弱点として最初から指摘されていた欠落なので、
   優先度を上げる価値がある
4. 上記が固まってから、アイテム拡張・他のアプリ・経済システムに順次着手

**ストーリー本編（章立て・会話イベント）の実装は、上記のシステム土台が整うまで後回しでよい**、
というのがこちら側の判断。会話イベントを先に作っても、それを表示する仕組み（キャラ切り替え等）が
無いと結局作り直しになるため。
